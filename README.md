# Lanmei — прототип посадочной

Живая страница: см. GitHub Pages этого репозитория (`index.html` → `blue/` и `violet/`).

- `проект/` — основной синий вариант: исходники React + Vite, картинки, собранный `dist/`
- `проект-фиолет/` — тот же код в старой гамме Lanmei
- `blue/`, `violet/` — копии `dist` под адресами для Pages; пересоздаются скриптом `публиковать.sh`
- `АКТУАЛЬНОЕ.md` — что где лежит, история сборок и решений
- `снимки/` — снимки экранов
- `00-каркас.md` — каркас страницы, шесть решений на блок

Пересобрать: `bash проект/build.sh` (нужен Node 24, `npm i` в папке проекта). Опубликовать: `bash публиковать.sh`.
