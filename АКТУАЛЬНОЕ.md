## Чем собрано

React + Vite + Tailwind через `web-artifacts-builder`. После `vite build` скрипт и стили
**встраиваются внутрь `index.html`**: с диска браузер не грузит внешний модульный скрипт,
а встроенный — грузит. Сборка в один файл через parcel не прошла: пакетному менеджеру нужны
разрешения на нативные сборки, обход через встраивание оказался проще и без зависимостей.

Пересобрать:
```bash
export PATH="$HOME/.nvm/versions/node/v24.16.0/bin:$PATH"
bash проект/build.sh   # vite напрямую + встраивание скрипта и стилей внутрь index.html
```

## CTA-система 18.09 — «кнопка не привлекательна, не побуждает»

и подписью выгоды под ней. В герое и на синей плите — белая с синим кругом (контраст к холсту), в карточках сметы
и в квизе — синяя с заливкой, плавающая — синяя с пульсом. Наведение: кнопка приподнимается, стрелка уходит
по диагонали. Тексты: «Рассчитать мою поставку» · «Получить смету по строкам» · «Получить смету за 48 часов».
На телефоне кнопка во всю ширину под текстом героя, до сцены.
